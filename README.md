# Git Branching Workflow Demo

This project demonstrates a complete Git branching strategy using:

- Production Branch
- HotFix Branch
- Integration Branch
- Feature1 Branch
- Feature2 Branch

## Git Concepts Demonstrated

- Branch Creation
- Commits
- Merge
- Rebase
- Tags
- Merge Conflict Resolution
- Git History Visualization

## Branch Structure

Production
├── HotFix
└── Integration
    ├── Feature1
    └── Feature2
